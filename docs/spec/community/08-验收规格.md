# 校园社区验收规格

状态：草案；以下为可执行的功能和质量验收，具体性能阈值、审核时限和资源预算需在基线测试后确认。每项记录环境、版本、测试数据、步骤、实际结果及证据，失败需关联问题和复测记录。

## A. 身份与访问

- [ ] 未登录访问发现、公开详情及机会详情成功；访问草稿、互动及发布时进入登录流程，返回原页面。
- [ ] 普通邮箱可接收验证并完成注册；过期、错误、重复使用验证码被拒；发送与尝试次数受限。
- [ ] 非大学生可注册使用；不要求学校邮箱或学生身份认证。账号资料、草稿与通知不能被其他用户读取或修改。

## B. 内容发布与审核

- [ ] 作者创建带图片的草稿并重新打开，字段与图片一致；非作者无权访问。
- [ ] 提交后状态为待审，未通过前访客、搜索及关注流均不可见；重复提交不产生重复任务。
- [ ] 审核通过指定版本后内容公开；驳回有原因；旧版本结论不能发布新版本。
- [ ] 审核与撤回并发只产生一个合法结果；发布后修改形成新版本，旧版的可见性遵循规格。
- [ ] 下架后直接访问、列表、搜索及缓存路径均不可见；异步索引可重建。

## C. 风控与机会信息

- [ ] 个人可提交兼职、家教信息；必填项缺失或有效期非法时阻止提交并指明字段。
- [ ] 大模型判定和人工审核绑定内容版本；模型超时、格式错误或不可用时进入人工待处理，不自动公开。
- [ ] 涉及金钱的卡片和详情均显示“信息来源未核实，请谨慎甄别”；已判定广告的内容另有广告标识，移动端不截断。
- [ ] 举报绑定目标与原因，重复提交受控；审核员可查看证据并按权限处理；处理有原因与审计。
- [ ] 申诉绑定原处理决定；复核结果可查询，不能泄露举报人身份。
- [ ] 到期机会不再以有效机会展示；关键条款修改须重新审核。

## D. 社区体验

- [ ] 发现、关注、搜索及话题分页无重复或遗漏；取关、下架后的内容按规则过滤。
- [ ] 点赞、收藏及关注重复操作幂等；评论未经审核不公开；通知去重且只能由本人读取。
- [ ] 头像圆形且异常回退；发布按钮、风险提示、弹窗焦点、键盘操作与桌面/移动断点符合界面规格。
- [ ] 各页面提供加载、空、错误重试、无权限及状态冲突反馈，表单避免重复提交。

## E. 安全与可靠性

- [ ] 验证越权、注入、XSS、CSRF（cookie 认证场景）、上传类型伪造、恶意文件及频率限制；日志不含凭证或敏感材料。
- [ ] 业务事务与 Outbox 同时成功或失败；模拟投递前后崩溃、重复与乱序，恢复后满足幂等和状态不变量。
- [ ] 数据库和对象存储备份异地保存；从备份恢复到独立环境并验证关键数据，记录实际 RPO/RTO。
- [ ] 模拟审核积压、数据库不可用、缓存丢失与发布失败，告警可定位，运行手册可执行，回滚及数据补偿留痕。

## F. 性能与上线门禁

- [ ] 以约 100 用户试用场景完成负载、容量和成本基线；确定可用性、响应时间及审核时效目标。
- [ ] 如执行 10 万模拟用户压测，先定义数据量、并发、读写比例、持续时间和资源规格；记录吞吐、错误率、P95/P99、瓶颈和成本；明确为模拟结果。
- [ ] 真实试用前完成云部署、域名和 HTTPS，审核及举报负责人、隐私说明、备份、告警和应急下架就绪；适用规则和必要合规事项完成核查。
