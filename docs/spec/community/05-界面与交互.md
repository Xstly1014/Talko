# 视觉与交互规格

## 设计方向与令牌

白色主背景，字节系浅蓝作为交互色；不使用官方商标。背景 #F7F9FC，表面 #FFFFFF，主色 #3370FF，浅蓝 #EAF2FF，主文字 #1F2329，次文字 #646A73，边框 #E5E6EB，危险 #E34D59。正文 14px/22px，辅助 12px/18px，标题 24px/32px；统一 4px 间距基数、8px 控件圆角、12px 卡片圆角。

## 桌面布局

≥1200px：左导航 224px，主区最大 1120px 居中，顶部栏 64px；内容流三列、列间距 16px，侧栏仅空间允许时显示。768–1199px：导航收窄、内容双列；<768px：顶部搜索、单列内容和底部导航，发布入口不遮挡内容，安全区留白。页面左右内边距桌面 32px、移动 16px。

## 组件细节

- 头像：圆形 object-fit: cover；导航 36px、卡片 28px、主页 96px、评论 32px；加载失败显示名称首字或默认图，alt 不重复朗读装饰头像。
- 发布按钮：主色填充、白字、8px 圆角，桌面最小 120×40px；移动端最小点击区域 44×44px；hover 加深，禁用态透明度 0.5 并说明原因。
- 内容卡片：封面宽度铺满，默认比例 4:3，object-fit: cover；标题最多两行，作者、发布时间和互动数完整可读；整卡可进入详情，按钮事件不触发卡片跳转。
- 内容详情：桌面图片与正文双栏，移动单列；支持多图切换、键盘操作和图片替代文本。机会信息突出有效期、发布方、核验状态及风险提醒。
- 表单：标签始终可见；必填标识；错误出现在字段旁并聚焦首个错误；异步提交防重复；离开未保存页面提示；图片上传前展示格式、大小、数量限制及预览。
- 反馈：骨架屏、无结果、重试及权限说明；Toast 不替代字段错误。破坏性操作使用对话框说明影响并要求确认；对话框支持 Esc、焦点约束和返回触发元素。
- 导航：当前项通过颜色和形状双重标识；控件支持键盘与可见焦点；文本和控件颜色应经对比度检测，不能仅靠颜色表示状态。

## 内容与隐私

发布时间采用相对时间并提供完整时间；机会联系方式按权限展示，勿将私人身份材料放公开页面。示例图片和数据应有授权，真实环境不依赖第三方演示图片。


## 金钱信息风险提示

涉及金钱的卡片封面下方、标题附近显示固定文字“信息来源未核实，请谨慎甄别”，详情首屏和联系方式附近再次显示；字号不小于 12px，使用文字与图标共同表达，不能仅靠颜色。确认属于广告时显示独立“广告”标识；窄屏不得截断提示。提示不表示发布主体已被核实，也不保证交易安全。
