# 页面规格

所有页面具备加载、空、失败重试、无权限和移动端适配；用户生成内容默认转义。详情深链需服务端重新校验可见性。

## 1. 发现首页

- 路由建议：`/discover`。
- 功能：推荐内容、分类与搜索入口；按发布时间展示已公开内容。
- 权限：公开内容可匿名读取；互动需登录。
- 验收：数据来自对应接口；提交显示进行中、成功和可恢复错误；列表分页不重复，空状态提供明确下一步。
