# 业务线与规则

## 角色

访客可浏览公开内容；受邀用户可发布、关注、互动及举报；作者管理自己的草稿与内容；审核员、运营及风控人员在独立服务工作，社区后端不信任前端传入角色。首期是否允许访客访问待确认。

## 内容生命周期

草稿 → 待审核 → 已发布 / 已驳回；已发布 → 已下架 / 作者删除；驳回后修改产生新版本重新提交。已发布内容编辑使用新版本，旧版保持可见直到新版本通过；审核结果必须绑定 revision_id。撤回与审核并发时条件更新，仅一个成功。下架立即阻断详情、Feed 和搜索的可见性；缓存异步清理。删除是否可恢复与保留期限待确定。

## 机会信息

机会为独立类型，至少包括发布方、类别、城市、工作内容、报酬及结算、期限、联系方式展示规则和资质材料；审核包含主体及内容核验。到期自动关闭，新版本变更关键条件须重审。平台不处理资金和交易；禁止押金、违规收费及虚假承诺。展示风险提示、举报入口和核验状态；审核不等于平台担保。发布者资质、学校认证和具体地域合规要求待核实。

## 关系与互动

关注唯一约束；取消关注立即影响关注流读取。点赞、收藏按用户和对象唯一，重复操作幂等；计数为展示值，可由事实记录重建。评论首期纳入审核与举报，默认不可编辑，可删除本人评论；审核未通过不可对外显示。用户冻结或内容下架时读取端统一过滤。

## Feed、搜索、通知

发现流首期按审核通过时间倒序，人工推荐配置独立；关注流展示关注之后发布内容，游标分页并读时校验关注关系、内容状态。搜索首期可基于数据库索引，过滤权限；规模增长后评估搜索引擎。审核结论、互动、举报/申诉结果以站内通知展示，通知去重，未读计数可重建。

## 举报、申诉、账号

举报记录对象、原因、说明和时间，处理结果不泄露举报人；同用户同对象待处理举报限制重复提交。申诉绑定处理决定与版本，提交后进入风控队列，结果留痕。账号注销提供申请、冷静期及撤销机制，具体期限和保留规则上线前决策；已公开内容的处理、法律保留和数据导出需明确。图片默认私有上传，审核通过后按受控访问策略展示。


## 已确认规则与重点业务线

访客可访问公开内容，登录后发布和互动；普通邮箱验证即可注册，学校邮箱与学生认证均非必要，不设置学生身份准入限制。历史页面目录中的“学生认证”为可移除页面，不属于首期要求。

个人可发布兼职、家教信息。涉及金钱的内容在卡片和详情展示清晰的风险提示：“信息来源未核实，请谨慎甄别”；若内容具有广告属性则额外标识“广告”，是否为广告依业务及适用规定判定。不得仅凭模型结论声称已核实发布方或保证安全。

### 重点一：内容与机会风控

覆盖提交前校验、文本和图片检测、大模型辅助判定、人工审核、举报、下架及申诉。模型返回结构化风险等级、原因与规则版本，但不应自行认定事实；模型超时、格式错误或无法判断进入人工队列。人工审核须具备版本绑定、处理原因、审计记录和冲突控制；模型调用记录需脱敏并控制保留。人工审核能力和处理时效是试运营前的硬约束。

### 建议重点二：内容生命周期与分发（待确认）

以发布版本、审核通过、进入发现/关注流、修改重审、下架撤回为一条完整链路。它与风控天然相连，能展示状态机、事务性事件、幂等、缓存一致性及故障补偿，也能在约 100 名用户下验证业务正确性。增量拉取与游标分页可作为该业务线中的优化实验；优先验证重复、漏读、下架过滤和数据更新，再根据负载决定是否深入推拉结合。无需假设大 V 或生产流量。
