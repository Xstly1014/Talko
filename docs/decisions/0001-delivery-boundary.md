# ADR 0001：首个社区交付边界

状态：实施中。用户已确认风控和内容生命周期与分发两条重点业务线，首期评论必须开放。

社区 Web 与 Go API 分别部署；审核后台属于后续独立前端服务。当前提供受主机访问控制保护的人工审核 CLI，不将审核菜单放入社区，不把它描述为完成了审核服务。模型适配接口存在，但不配置供应商，全部进入人工审核。

MySQL 是事实来源；Outbox 与业务更新同事务，当前本地消费者完成投递和通知，消费事务与确认同提交，可在崩溃后重放。仅有 100 用户试运营目标，当前未执行 10 万模拟用户压测。没有必要在当前数据量下引入 Kafka 或 Redis 来替代数据库事务，后续按观测结果增加。
