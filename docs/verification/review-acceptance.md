## 浏览器验收

1. 在独立 :5174 登录本机开发人员账号。
2. 在社区提交昵称与简介修改；社区保持旧公开资料，显示待审核。
3. 工作台出现 profile 任务，领取后填写依据并批准。
4. 刷新社区后展示已通过的新资料与审核原因。见 review-decision-browser.png。
5. 发布评论，本人可见待审提示；后台查看评论正文和关联内容，领取并批准；社区移除待审提示并出现举报入口。
6. 使用评论举报弹窗提交说明；工作台展示举报、评论证据与关联内容；填写依据不予处置后，社区个人举报记录显示相同处理结果。
7. 后台与用户结果分别见 review-report-browser.png、community-report-browser.png。

本地浏览器联调还发现了旧版删除遗留的无效待审任务：新版决定接口已阻断错误发布，通过 004 迁移校正并写入审计；新版删除操作在事务中直接取消相关任务。
