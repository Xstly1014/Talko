# 当前实施状态

## 已落地并使用真实持久化

- 邮箱验证码与注册、bcrypt 密码、哈希会话、注销会话、基础进程内限流、同源写保护。
- 图文及结构化机会草稿、图片归属、不可变版本、提交和撤回、人工审核、自审阻断、审计。
- 关注、公开与关注流、搜索、收藏和点赞；关注流读取校验关系与公开状态，索引由事务 Outbox 填充。
- 评论提交、人工审核后可见、本人待审可见及删除。
- 举报、人工下架、申诉和复核结论通知；CLI 操作有审计。
- 社区前端接入 API；未使用浏览器存储模拟业务数据。

## 真实试运营前的必做工作

- 完成独立审核后台的人员身份、权限、分配与复核能力。现有 CLI 的 actor 为操作记录，不是企业身份认证；禁止对公网暴露数据库或该命令。
- 完成资料审核、评论举报、评论/记录列表完整分页、关注粉丝列表、账户恢复及注销/数据导出；逐项对照页面规格，不以目录数量计完成度。
- 对象存储、容量配额、备份恢复及图片审核；机会广告属性判定与发布规则。
- 生产邮件鉴权和传输加密，分布式限流、反枚举、会话管理、账号状态、隐私策略和运营联系人。
- Outbox 重试退避、死信及告警阈值、按批次分发游标、任务处理超时、对账补偿与运营手册。
- CI/CD 审批与回滚、容器和数据库指标、集中日志追踪、负载测试、安全测试与恢复演练。
- 完整 OpenAPI 字段契约、版本化后续迁移（当前为首版初始化 schema）、精确需求追踪。

以上未完成项都是上线门禁；当前不是可上线交付。没有模型配置时内容保持人工审核，不自动通过。
