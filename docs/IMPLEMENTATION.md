# 当前实施状态

## 已落地并使用真实持久化

- 邮箱验证码注册、bcrypt 密码、哈希会话、注销、基础进程内限流与同源写保护；游客可浏览公开内容。
- 图文与结构化机会、图片归属、不可变版本、提交撤回、人工审核、原作者自审阻断、广告分类标识与机会过期读取过滤。过期机会不得审核通过。
- 关注、公开与关注流、搜索、收藏和点赞。分发由事务 Outbox 填充，公开读取再次校验关系与内容状态。
- 评论先审后公开、本人待审可见、删除时取消任务；父内容删除或下架时取消关联待审任务；评论列表分页。
- 昵称、头像和简介以独立版本审核，旧公开资料在待审期间持续展示，新提交替代旧待审变更。
- 独立审核 API 与 Web，独立人员会话、角色授权、15 分钟任务领取保护、处理依据、任务详情图片和评论上下文。
- 图文举报绑定举报发生时的不可变版本；评论举报、去重、证据详情、人工下架或不处置、双方通知与审计。
- 申诉由非原审核员、非作者复核；可维持或将仍有效版本重新送审。原审核结论保留，新任务独立编号，不跳过发布审核。旧版本、删除、下架与过期机会拒绝重开。
- 个人审核记录、内容举报、评论举报、申诉和通知记录；审核队列、案件与审计列表分页。
- 版本化迁移与迁移互斥锁；历史失效任务校正及审计。社区、审核前端接入真实 API，未使用浏览器存储模拟业务。

## 部署与分发可靠性增量

- Outbox 持久化失败次数、指数退避、第 8 次进入死信、失败隔离及审计重放；独立 worker 入口与采集端点。
- 社区/审核 HTTP 请求数与耗时、数据库连接池、待审队列、Outbox 与 Go 运行指标；数据库采集失败明确返回 503。
- 飞书签名适配器与 Alertmanager 覆盖配置，错误投递返回失败，触发/恢复本地契约测试通过；尚未接入真实机器人。
- 独立服务容器、Prometheus/Grafana/Alertmanager、镜像 CI、发布/兼容回滚及备份/隔离恢复脚本已编写。基础 Compose 配置与脚本语法通过，Docker 服务端无法启动，因此容器执行验收仍待完成。
- 原生 WSL MySQL 真实备份隔离恢复通过，完整 SQL 一致；当前源库没有图片，图片恢复验收仍待完成。详见 verification/infrastructure-acceptance.md 与 runbooks/infrastructure.md。

## 本轮验证范围

真实 MySQL 集成测试验证内容分发与可见性、人员权限、领取冲突/过期、资料隔离、举报证据跨版本保留、申诉重开与旧版本保护。浏览器验证人员登录、资料提交领取批准与公开资料更新。详见 verification/review-acceptance.md。

本机应用与开发邮件保持运行；本机能访问与通过这批测试，不代表已满足公网运营条件。

## 后续开发优先级与上线门禁

### 下一批：账户与治理操作完整性

- 密码找回、会话管理、账号状态与封禁/解封、账户注销/数据导出、关注粉丝列表。
- 人员账户开通、停用、权限变更的安全管理流程与审计；多因素认证或外部身份提供商；操作频率与异常行为控制。
- 举报与申诉时限、案件分配与升级、原因字典、通知可达性、处理对账。
- 完整 OpenAPI 字段契约与需求到验收的精确追踪。

### 随后：分发可靠性与媒体基础设施

- 完成独立 worker 容器与告警运行验收；补按批次分发游标、任务超时、对账与补偿。重试退避、死信及审计重放已有代码和数据库测试。
- 对象存储、容量配额、生命周期清理、授权访问、备份恢复与图片审核。
- 生产邮件鉴权和传输加密、分布式限流与反枚举；模型供应商选定后再接适配器，失败仍转人工。

### 上云前：运营与发布门禁

- 运营联系人、内容规则与隐私处理流程、风险应急与数据治理制度。
- 在应用指标基础上补宿主机/容器/MySQL 服务端 exporter、集中日志与追踪；飞书真实送达、备份自动化及异机恢复、图片恢复与恢复耗时验收。
- CI/CD 发布审批与回滚、密钥管理、容量预算、漏洞与权限测试、负载测试及恢复演练。
- 以约 100 名真实用户的试运营容量规划；十万用户仅作为压测数据规模，具体并发与 SLO 需另行决策并验证。

目前没有供应商模型、云服务器或域名。所有未完成门禁必须在邀请真实用户进入公网环境前完成验收。
